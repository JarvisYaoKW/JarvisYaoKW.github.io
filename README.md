# 词间 · IELTS Typing Studio

雅思与四六级词汇打字练习。支持预置词库、导入词库、字母提示、常错本、收藏、词形词族练习与羊群草场进度。

网站：https://jarvisyaokw.github.io/

词库、练习进度和金币保存在当前浏览器。换设备或换网址前，请导出完整备份，再在目标浏览器恢复。清除网站数据会清除本机进度。

## 发布

GitHub Pages 使用 main 分支根目录。此目录为独立的浏览器版本，可直接静态托管。

## 数据来源

预置词库及英文释义主要来自 ECDICT（MIT）。完整许可、各词库来源及整理说明见 wordbooks/NOTICE.txt、wordbooks/ECDICT-LICENSE.txt 和对应来源文件。
