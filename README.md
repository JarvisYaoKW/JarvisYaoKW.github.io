# 咩词 · Mieci

从自己的雅思备考需求出发，做一个能持续使用的英语打字练习工具。

「咩」既是羊的叫声，也有粤语“什么”的意思。词条的记忆进度化作羊群，答对就把对应词数带到记忆草场，进入加练时它们会逃回来。巨大羊、大羊、中羊、小羊、小小羊分别代表 500、100、50、10、1 词，两侧草场按当前词数自动组合。

## 为什么做

我希望同时练习英文拼写和键盘输入，并能使用自己的词库。练习需要随时中断、下次继续，新导入的词也应加入当前轮次。常错词和收藏词需要再次出现。

咩词将这些需求做成可公开访问的网页。无需注册学习账号，词库和练习记录保存在当前浏览器中。

### 每日学习

在练习设置中切换到「每日学习」，选择词库、新词目标和每日总量，再生成任务。
例如总量 150、到期复习 100，会先安排 100 词复习，再安排最多 50 个新词。新词目标可设为 0，仅复习。
新词先照打，隔几个词再按字母提示回忆拼写；两步使用同一条输入横线。新词和复习的字母提示可分别设置为 0–100%。

复习使用 1、3、7、14、30 天的间隔；答错后在当前任务稍后重练，下一次复习缩短至 1 天。
逾期词优先，同一天到期时优先常错词。超出上限的到期词保留在待安排复习中。
历史成绩会作为已练参考纳入首批复习，准确学习日期从启用本功能开始记录。

任务生成后固定保存，跨日未完成也可续练。设置修改与新导入词用于下一份任务；一份任务完成后当天不重复生成。
跳过表示暂缓，计入暂缓数，不计完成词数。照打不计对错、金币或抓羊；正式回忆拼写答对后得 1 金币，并在当前每日任务的草场带回对应的羊。
整库练习保留独立轮次和当前输入。两个计划共用词库、常错本、收藏、成绩与金币。

## 快速运行

需要 Node.js 22 或更高版本。运行和测试使用内置模块，无需安装运行时依赖。

```sh
git clone https://github.com/JarvisYaoKW/JarvisYaoKW.github.io.git
cd JarvisYaoKW.github.io
npm start
```

打开 `http://127.0.0.1:8080/`。自定义端口：`npm start -- --port=8081`。

```sh
npm test       # 关键学习规则与数据验证
npm run check  # JavaScript 语法检查
```

完整步骤见[开发与测试](docs/DEVELOPMENT.md)。线上通过 GitHub Pages 的 `main` 分支根目录发布。

## 数据与边界

- 学习数据保存在当前浏览器 IndexedDB；跨设备通过完整备份迁移。清除网站数据会清除本机记录。
- 词典补全与发音会向第三方服务请求当前词条或音频。离线能力取决于资源是否已缓存。
- BIN 解析基于已验证样本格式，不保证兼容所有有道导出版本。
- 羊群与奖励用于练习反馈，尚未通过对照研究验证长期记忆效果。
- 目前没有持续的用户量、留存率或学习成效统计。
