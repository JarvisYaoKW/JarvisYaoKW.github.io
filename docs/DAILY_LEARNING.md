# 每日学习实现

`daily-learning.mjs` 管理 `state.daily`：词条级复习记录、下次任务设置、当前任务和最近 365 份任务摘要。数据与完整备份一同保存在本机，调度无需联网。

日期使用设备本地日历日；日期加减使用 UTC 日历运算避免夏令时出现 23/25 小时偏差。未完成任务跨日保留；完成当天不重新抽题。新词排队仅生成时洗牌，复习按到期日、错误次数排序。

每日任务拥有单独的 round 兼容状态。正式回忆提交通过 `practiceState()` 传入原有判分和金币引擎，共享词条统计与钱包，但不更改整库轮次。照打使用独立暴露步骤，完成后进入同词回忆，不改变正式统计或羊的位置。错词回到任务尾部；跳过标为暂缓，并将已有复习记录推迟至明天。

新词回忆成功后初次间隔为 1 天，之后成功依次间隔 3、7、14、30 天，30 天封顶。当天正式失败后，后续成功仍只间隔 1 天；同一天整库重复答对不会继续拉长间隔。这是可解释的初版固定间隔规则，后续可替换为更细的记忆模型。

旧数据有正确/错误次数但缺少日期时，迁移为「历史已练、待复习」，不反推学习日期。无成绩的新词仍视为新词。与旧版浏览器状态兼容，`validDailyState()` 拒绝不完整任务覆盖现有进度；草场只读取当前激活计划的数据。

验证：`tests/daily-learning.test.mjs` 覆盖选词上限、错词重练、间隔变化、跨日续练、同日防重建、复制曝光、金币、备份/草稿、旧数据迁移、筛选和普通对象属性名词条。浏览器验证补充实际快捷键、UI 设置、刷新恢复和窄屏布局。
